# README visual system

Native SVG artwork inspired by the dark teal, mint and orbital signal style of ruvnet/ruvnet assets/ruvnet/cognitum-banner-v2.svg (reference blob a50f9bdd5d57cf2d3c51b31b1a47b7276247505b).

All assets use local vector geometry, system fonts and CSS animation. No scripts, external resources, embedded HTML or live data. Motion is decorative; every label is visible without animation. The prefers-reduced-motion media query disables all animation.

Keep Markdown headings, copyable commands and text documentation as the source of truth. Wrap images in Markdown links when navigation is useful; embedded SVG links are not required. Guides illustrate documented workflows, not measured results. Preserve the viewBox when resizing.

Review at desktop and phone widths, with reduced motion enabled and with animation disabled. Check SVG XML, referenced paths and README anchors before publishing.
